## Later

- `orchestrator-state` — Orchestrator that tracks the current goal, sourced findings and plan in typed state, asks the user when the goal is unclear, and never sends full chat history
- `context-inspector` — UI that shows thinking traces and the orchestrator's current context at any moment
- `environment-and-identity` — Orchestrator aware of date and time, user name and computer name, and of the same user across computers for external memory
- `subagents` — Subagents with per-subagent tool lists and model tags
- `tools-first-set` — Tools: web search, RAG query, memory access, pre-programmed web scrapers and API calls
- `a2ui-nicegui` — A2UI v1.0 in NiceGUI: widgets ported from TypeScript compiled with esbuild, custom HTML and SVG components, bundles shipped prebuilt in the wheel
